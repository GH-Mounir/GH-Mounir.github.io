### Human Behavior Through Process Mining

> *"Treating human interactions as behavioral trajectories rather than isolated observations."*

#### Key Pipeline
```
Events → Event Logs → Behavioral Processes → Latent States
```

#### Analytical Artifacts
- **Directly-Follows Graphs (DFG)** & behavioral Spaghetti Model decomposition.
- **Variant Analysis** identifying user navigation journeys and friction paths.
- **Stochastic Transition Matrices** quantifying probabilities of switching between engagement states.
- **Process Discovery Pipelines** using Celonis and PM4Py.
