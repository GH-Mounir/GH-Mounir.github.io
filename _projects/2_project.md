### Event-Centric Experimentation Infrastructure

A high-precision Progressive Web Application (PWA) engineered for real-time QoE experimentation, telemetry collection, and unconstrained subjective evaluation under realistic network conditions.

#### Key Capabilities
- **DASH Playback Monitoring**: Frame-accurate telemetry and rate adaptation tracking.
- **IndexedDB Event Logging**: Asynchronous offline queueing and loss-resilient event buffering.
- **Context Acquisition**: Real-time acquisition of device states, ambient factors, and cellular RF metrics.
- **Crowdsourced Evaluation**: Standardized workflows for distributed subjective testing.

#### Technology Stack
`PWA` • `JavaScript / TypeScript` • `IndexedDB` • `Pub/Sub Architecture` • `DASH Streaming` • `Fog Telemetry`
